# Brag Plan: GrandPA2-Buddy

## What is this app?
An MCP (Model Context Protocol) server that gives AI agents 210 tools to drive a grandMA2 lighting console over Telnet, with an embedded agent core that plans, executes and remembers.

## The angle
Lighting consoles are famously command-line-heavy and unforgiving. The joke and the claim are the same: a "buddy" that speaks console fluently, and is fenced in by a 3-layer safety model so it cannot do anything the operator would not allow.

## Hook (0-3s)
Typed line on a dark console screen: "What if your lighting console could listen?" Held ~2.4s after typing.

## Key moments
- Title reveal with a 0 -> 210 tool counter ("210 MCP tools").
- Agent run: goal typed, then classify / plan / validate / execute / verify / trace tick off one by one.
- Safety: three overlapping rings, "OAuth scope ∩ MA2 native rights ∩ console floor".

## Outro / punchline
"3,705 tests before it touches your rig." Then "GrandPA2-Buddy. Let the lights listen."

## User flow worth showing
1. Entry: operator states a goal in plain language.
2. Key action: run_agent_goal loops classify -> plan -> validate -> execute -> verify -> trace.
3. Result: every step ticked; the console does the work.

## Tone
- Preset: cinematic
- Creative direction: quiet stage-blackout trailer, one warm spotlight, deadpan technical claims
- Interpretation: big type, long holds, few scenes; drama from restraint, not noise.

## Duration: 20s

## Audio direction
- Role: warm bed with sparse professional accents
- Music: bundled "happy-beats-business-moves-vol-1" (120 BPM), low under the story
- Music treatment: from 0s, ~0.35 volume, 1s fade-in, 2s fade-out
- Music cue guidance: preset read; beat grid ~0.5s; strong cues at 16.02s, 17.02s, 18.02s used for outro landing
- Audio-reactive treatment: none (kept simple; readability first)
- SFX posture: sparse, motion-matched
- Restraint rule: no SFX over the safety scene beyond three soft clicks

## Storyboard

### Scene 1 — Hook — 3s
Dark screen, typed hook line with key ticks.
Sequential/interaction: yes — text types character by character (hold ~2s after typing).
Transition mood: clean → Scene 2

### Scene 2 — Reveal — 4s
"GrandPA2-Buddy" title, counter 0→210, "MCP tools · grandMA2 · Telnet".
Sequential/interaction: counter ticks up.
Transition mood: clean → Scene 3

### Scene 3 — Agent run — 6s
Terminal card: run_agent_goal("warm wash, 12 fixtures"), six steps tick in ~0.5s apart, each label held; full set held ~1.5s.
Sequential/interaction: yes — six steps appear one by one.
Transition mood: hard → Scene 4

### Scene 4 — Safety — 4s
Three rings converge: OAuth scope, MA2 native rights, console floor. Caption "All three must agree."
Sequential/interaction: yes — rings arrive one by one.
Transition mood: soft → Scene 5

### Scene 5 — Outro — 3s
"3,705 tests before it touches your rig." then wordmark + "Let the lights listen."
Transition mood: fade out
